# Space Shooter

![demo](/demo.png)

A work-in-progress 2D space shooter game built with the Defold game engine. 🚀

This repository uses Defold for fast, cross-platform game development with Lua scripting, sprite atlases, and scene collections. It is currently under active development, so features, assets, and gameplay are still being improved.

🚀🚀 This is a great opportunity to put your game development and Defold skills into practice in a real project, learn by building, and share the experience with other people who are passionate about creating videogames. One of the goals of this project is to create a welcoming space to share ideas, collaborate, and meet more people from the community who are interested in game development.

🖖 If you are looking for a friendly place to contribute, this repository is a great starting point. Whether you want to improve gameplay, add art, fix bugs, or experiment with new systems, your help is very welcome. 

## Contributing

Open source contributions are welcome. To collaborate effectively:

1. Review open issues and choose one that matches your interests or skills.
2. Comment on the issue and ask to be assigned before you start working.
3. Once assigned, fork the repository to your own GitHub account.
4. Clone your fork locally and create a new branch for your work.
5. Make your changes, test them, and keep commits focused and descriptive.
6. Push your branch to your fork and open a pull request against this repository.
7. Include a clear description of the problem, the changes made, and any testing steps.

👉 If an issue is not detailed enough, feel free to ask questions and request clarification before starting work on it. The goal is to make collaboration easy, friendly, and enjoyable for everyone.

🙌 If you do not find an existing issue, feel free to open one describing your idea or bug report.

Thanks for collaborating and helping make this game better!
